# funnelbase_flutter_platform_interface

The contract between [`funnelbase_flutter`](https://pub.dev/packages/funnelbase_flutter) and its
platform implementations: the shared types and `AnalyticsPlatform`, whose default instance refuses
every call. Apps never import it. See
[docs/sdk-flutter.md](https://github.com/Funnelbase/funnelbase-flutter/blob/main/docs/sdk-flutter.md).
